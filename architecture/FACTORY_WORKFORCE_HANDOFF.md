# Factory ↔ Mina-Video Workforce Reuse

Factory may temporarily route idle/verified capability to Mina-Video for
bounded media work such as quality research, render diagnostics, provider
experiments, and provenance review.

Mina-Video remains execution-only. Temporary assignments never grant:
ownership, billing, credentials, governance, or final-live-activation.

Every assignment has:
- an explicit task;
- a bounded scope;
- an expiry condition;
- an evidence requirement.

This preserves the single-control-plane architecture while preventing useful
Mina-Video capacity from sitting idle.
